# 🐾📚 Mike na Trilha do Saber

O Mike na Trilha do Saber é uma plataforma web educacional gratuita desenvolvida para auxiliar estudantes no aprendizado de inglês.

## 🎯 Objetivo

Desenvolver uma plataforma web educacional gratuita que utiliza tecnologia e inteligência artificial para ajudar pessoas a aprender inglês de forma acessível, organizada e motivadora, por meio de testes de nível, planos de estudo personalizados, acompanhamento do progresso, gamificação e suporte inteligente.

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
